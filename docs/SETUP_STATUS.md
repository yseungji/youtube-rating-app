# 초기 설정과 남은 작업

## 저장소 운영 기준

- 비공개 저장소로 운영합니다.
- 기본 브랜치는 `main`으로 사용합니다.
- 기능별 브랜치에서 작업하고 PR로 합칩니다.
- Squash merge와 병합 후 브랜치 자동 삭제를 사용합니다.
- 다른 팀원 1명의 리뷰를 팀 규칙으로 합니다.

보호 브랜치의 실제 강제 여부는 GitHub 설정을 확인해야 합니다. GitHub Free의 비공개 저장소에서는 보호 브랜치가 지원되지 않습니다. 지원하는 계정 플랜을 사용할 때만 리뷰·강제 push 금지 규칙을 서버에서 강제할 수 있습니다. 이 문서는 적용되지 않은 보호 규칙을 적용 완료라고 주장하지 않습니다.

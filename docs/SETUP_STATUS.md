## main 보호의 적용 상태

현재 이 비공개 저장소에서는 GitHub가 보호 브랜치 적용 요청에 Pro 업그레이드 또는 공개 저장소 전환이 필요하다고 응답했습니다. 유료 전환과 공개 전환은 하지 않았습니다.

따라서 PR과 다른 팀원 1명의 리뷰는 팀 운영 규칙이며 서버에서 강제되는 보호 규칙은 아닙니다. 보호 브랜치를 지원하는 플랜을 사용할 때 리뷰 1명, 관리자 포함 적용, 강제 push·삭제 금지 등을 설정할 수 있습니다.

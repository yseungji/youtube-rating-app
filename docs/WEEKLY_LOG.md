# 주간 작업 기록

주간 보고서를 쓰기 위해 팀원 세 명이 각자 한 일을 주 단위로 적는 문서입니다.

## 적는 방법

- 한 주는 월요일부터 일요일까지입니다. 1주차는 2026-08-31(월)부터 시작합니다.
- **자기 이름 아래에만** 한 줄씩 추가합니다. 다른 사람의 줄은 고치지 않습니다. 이렇게 하면 여러 명이 동시에 고쳐도 충돌이 거의 나지 않습니다.
- 형식: `- 날짜 한 일 (작업 번호, PR 번호)`
  - 예: `- 11/5 하단 5탭 뼈대 구현 (2.2, #4)`
- 기능 PR을 올릴 때 이 파일의 기록도 같은 브랜치에 넣어 함께 올립니다. 회의·설계처럼 코드가 없는 일은 다음 PR에 함께 넣거나 `docs/weekly-log-주차` 브랜치로 따로 올립니다.
- 팀이 함께 한 일(회의, 발표, 합의)은 "팀 공통"에 적습니다.
- 주차 섹션이 없으면 아래 형식을 복사해 맨 위에 추가합니다.
